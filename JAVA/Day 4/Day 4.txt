automatic type promotion in expression
1byte = 256
int a = 257
byte b = (byte) (a)  // 1   

Type promotion in expressions refers to how smaller data types (like byte, short, or char) are automatically converted to larger data types (like int or double) during operations in Java. This ensures calculations are performed without data loss or overflow.

For example:
byte a = 10;
byte b = 20;
int result = a + b; // `a` and `b` are promoted to `int` before addition.

java follows Unicode.

int a = 'A'

'A' is a character literal and in Java, characters are internally stored as their Unicode values.
The Unicode value of 'A' is 65, which is an int.
When you assign 'A' to int a, Java automatically promotes the char to int (type promotion).
